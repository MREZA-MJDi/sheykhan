# پلیر فارسی Shaka در شیخان

## وضعیت این شاخه

این تغییر، Shaka Player را به‌عنوان یک وابستگی محلی پروژه وارد می‌کند و کامپوننت پلیر فارسی را آماده می‌سازد. اتصال آن به پخش فعلی SpotPlayer عمداً انجام نشده تا تا زمان آماده‌شدن pipeline استریم و DRM خودمان، رفتار فعلی دانش‌آموز تغییر نکند.

## استفاده از کامپوننت

کامپوننت Blade آماده است:

```blade
<x-video.shaka-player
    :manifest-url="$authorizedManifestUrl"
    title="جلسهٔ آموزشی"
    :watermark="auth()->user()->name . ' · شیخان'"
/>
```

`$authorizedManifestUrl` باید از backend مجاز تولید شود؛ نه از یک فایل خصوصی که URL مستقیم و دائمی آن در اختیار کاربر قرار گرفته باشد. برای Shaka معمولاً manifest از نوع DASH یا HLS نیاز داریم و فایل‌های قطعه‌ای، CORS و مجوزهای منبع نیز باید درست تنظیم شوند.

## ترجمه و بارگذاری

- وابستگی Shaka نسخهٔ دقیق `5.3.2` است.
- ترجمهٔ رسمی فارسی از پروژهٔ upstream نگهداری می‌شود.
- `resources/js/app.js` فقط وقتی کامپوننت روی صفحه وجود دارد، ماژول Shaka را به شکل lazy import بارگذاری می‌کند.
- زبان کنترل‌ها `fa` است، صفحه RTL می‌ماند، و گزینه‌های ذخیره/کپی فریم در منوی نمایان پلیر قرار نگرفته‌اند.

## مرز امنیتی

این شاخه به‌تنهایی DRM یا حفاظت آفلاین را پیاده‌سازی نمی‌کند. برای مرحلهٔ DRM باید pipeline بسته‌بندی ویدئو، کلیدها، endpoint صدور مجوز، کنترل entitlement، مجوز پایدار آفلاین و سیاست ابطال را جداگانه طراحی و تست کنیم. واترمارک سمت مرورگر یک deterrent است، نه تضمین جلوگیری از ضبط صفحه.

## ساخت

```bash
npm ci
npm run build
```

این دستورها باید در محیط توسعه/CI اجرا شوند تا importهای پکیج و CSS با نسخهٔ واقعی Shaka تأیید شوند.
