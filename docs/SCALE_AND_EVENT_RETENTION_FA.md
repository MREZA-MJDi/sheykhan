# مقیاس‌پذیری و نگهداری رویدادهای محتوای محافظت‌شده

## چه چیزهایی در این جدول‌ها ثبت می‌شود؟

- `protected_file_views`: بازشدن و مشاهدهٔ صفحه‌های فایل‌های خریداری‌شده.
- `protected_learning_media_views`: مشاهدهٔ محتوای آموزشی خصوصی.
- `spot_player_playback_views`: بازشدن پلیر ویدئوهای SpotPlayer.

این جدول‌ها تاریخچهٔ دسترسی‌اند، نه داده‌های اصلی ثبت‌نام یا پرداخت. ممکن است برای پیگیری دسترسی و بررسی رخدادها لازم باشند؛ بنابراین برنامه هیچ حذف زمان‌بندی‌شده‌ای را به‌صورت پیش‌فرض اجرا نمی‌کند.

## بررسی قبل از حذف

ابتدا فقط تعداد رکوردهای قدیمی‌تر از بازهٔ موردنظر را ببینید:

```bash
php artisan protected-media-events:prune --days=365
```

این دستور فقط گزارش می‌دهد و داده‌ای حذف نمی‌کند.

## حذف تأییدشده

پس از بررسی نیازهای حقوقی، پشتیبانی و گزارش‌گیری، همان بازه را با `--force` اجرا کنید:

```bash
php artisan protected-media-events:prune --days=365 --force
```

- حداقل بازهٔ قابل قبول ۳۰ روز است.
- حذف به صورت دسته‌های ۵۰۰تایی انجام می‌شود تا یک حذف بزرگ، حافظه و زمان یک درخواست را اشغال نکند.
- این دستور فقط سه جدول رویداد مشاهده را پاک می‌کند؛ سفارش، پرداخت، ثبت‌نام، لایسنس یا فایل اصلی حذف نمی‌شوند.
- اجرای خودکار در Scheduler عمداً فعال نشده است. تعیین بازه و دفعات اجرا باید با سیاست نگهداری دادهٔ کسب‌وکار هماهنگ شود.
- پیش از اجرای Production، از دیتابیس نسخهٔ پشتیبان قابل‌بازیابی تهیه کنید.
